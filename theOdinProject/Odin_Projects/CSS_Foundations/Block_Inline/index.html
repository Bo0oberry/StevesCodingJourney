Block and Inline

Introduction

In the previous lesson, we discovered that different display types have unique box models, and we can modify the box calculation by changing the box-sizing property. CSS has two box types: block and inline boxes, which determine element behavior and interaction. The display property controls how HTML elements appear on the webpage. We will explore its various options further in this lesson.

Lesson Overveiw

This section contains a general overview of topics that you will learn in this lesson.

  • You'll learn about “Normal flow”.
  • You'll learn the difference between block and inline elements.
  • You'll learn which elements default to block and which elements default to inline.
  • You'll learn what divs and spans are.

Knowledge Check

What is the difference between a block element and an inline element?

  • Inline:

    • Height and Width are only affected by content
    • Top and botttom padding will overlap with other elements

  • Block

    • Height and Width values are respected
    • element is set on new line
    • padding will push other elements away
What is the difference between an inline element and an inline-block element?

The inline-block:

  • Height & Width values are respected
  • top / bottom padding will push elements awaay
  • will NOT start on new line, instead will be set inline with prev element
